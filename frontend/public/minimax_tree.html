Alpha-Beta Pruning
Why cut off branches?
If Blue knows it can guarantee a score of 12 (by patching Node 8), it evaluates the alternative: Patching Node 5.

As soon as Red finds a response that drops the score to 5, Blue stops evaluating that branch. Blue knows patching Node 5 is a bad idea, so it doesn't waste time calculating Red's other possible attacks.
